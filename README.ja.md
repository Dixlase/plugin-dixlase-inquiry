# Dixlase Inquiry

For English, see [README.md](./README.md).

Dixlase 用の問い合わせフォームプラグイン。

- 固定 URL プレフィックス配下(既定 `/inquiry`)の問い合わせフォーム
- 氏名・メール・本文は必須、ふりがな / 件名 / 電話 / 郵便番号 / 住所 / 性別は個別に表示・必須を切り替え可能
- 1 ページ完結 / 確認ページ分離の 2 モード
- 管理者通知メール + 自動返信メール(テンプレート変数あり)
- プライバシーポリシー同意のオプション(完全 URL またはサーバー絶対パスをリンク先に指定可)
- CAPTCHA capability への opt-in(任意の CAPTCHA プラグインがウィジェットを取り付け可能)
- IP 単位の送信スロットリング
- 固定ページ等に貼れるショートコード対応

## 機能

- **公開フォーム** — 設定可能な URL スラッグ(既定 `/inquiry`)。1 ページ完結 / 確認ページ分離を切替可能。
- **項目切り替え** — 氏名・メール・本文は常に必須、ふりがな / 件名 / 電話 / 郵便番号 / 住所 / 性別は表示・必須を個別に切替可能。
- **名前順モード** — auto(ロケール判定)/ 西洋順 / 日本順。
- **プライバシー同意** — 任意のチェックボックスと、完全 URL またはサーバー絶対パスを受け入れるリンク先。
- **メールテンプレート** — 管理者通知と自動返信、いずれも `{{variable}}` 変数置換に対応。
- **CAPTCHA opt-in** — 互換 CAPTCHA プラグインが `captcha` capability 経由でウィジェットを取り付け可能。
- **送信スロットリング** — IP 単位の連投制限。最大試行回数・解除分数を設定可能。
- **問い合わせ管理** — 管理画面で一覧 / 詳細 / ステータス / 一括削除。
- **ショートコード** — `[dixlase-inquiry-form]` でホストページに埋め込み可能。
- **ロール権限** — 管理メニューごとにロール権限を設定可能。
- **ダッシュボード通知** — 新着件数および CAPTCHA 未設定の警告を表示。

## インストール

管理画面の **ダッシュボード → プラグイン** から本プラグインを検索し、ダウンロード → 有効化します。有効化すると本プラグイン用のテーブルが自動で作成されます。

## 使い方

有効化すると管理画面のサイドバーに **問い合わせ管理** が追加され、一覧 / 詳細 / 設定の各画面で問い合わせを操作できます。

公開 URL は設定スラッグから組み立てられ、既定の `inquiry` のときは `/inquiry` で公開されます。

他のページにフォームを埋め込みたい場合は、`[dixlase-inquiry-form]` ショートコードを目的の位置に挿入してください。

## Capabilities

本プラグインは `plugin.json` で以下の capability を宣言しています。

- **`captcha`** — 互換 CAPTCHA プラグインから、`CaptchaFormProviderInterface` 経由で問い合わせフォームにウィジェットを取り付けるための契約。
