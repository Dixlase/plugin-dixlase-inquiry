# Security Policy

Dixlase Inquiry is part of the Dixlase Project. Security reporting is coordinated centrally across the Project — there is no separate per-plugin disclosure channel.

For the Japanese version, see [SECURITY.ja.md](./SECURITY.ja.md).

## Reporting a vulnerability

**Please do not file public GitHub Issues for security vulnerabilities.**

To report a vulnerability in Dixlase Inquiry (or in any Dixlase component), follow the disclosure process documented in the Dixlase Core repository:

- https://github.com/Dixlase/dixlase-core/blob/main/SECURITY.md

When reporting, please mention that the vulnerability is in **Dixlase Inquiry** (this plugin) so the maintainers can route the report correctly.

## Supported versions

Until a stable 1.0 release is published, only the latest tagged release of Dixlase Inquiry receives security fixes. Pre-1.0 versions may be superseded without backports.

## Scope

This policy covers code in the [`plugin-dixlase-inquiry`](https://github.com/Dixlase/plugin-dixlase-inquiry) repository. Vulnerabilities in Dixlase Core, other official plugins, or third-party dependencies should be reported to their respective maintainers via the channels listed in Core's `SECURITY.md`.
