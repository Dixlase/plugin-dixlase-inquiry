# DixlaseInquiry 管理画面設定ガイド

## 概要

DixlaseInquiryプラグインの設定は、管理画面の「設定」→「お問い合わせ」から行います。

**アクセス方法**: 管理画面 → 設定 → お問い合わせ

## 設定項目一覧

### 1. フォーム項目設定

フォームに表示する項目とその必須設定を管理します。

#### 名前の表示形式

| 設定 | 説明 |
|------|------|
| 日本式 | 姓 → 名 の順で表示（デフォルト） |
| 欧米式 | 名 → 姓 の順で表示 |

#### フィールド設定

| フィールド | 表示設定 | 必須設定 | デフォルト |
|-----------|---------|---------|-----------|
| 名前 | 常に表示 | 常に必須 | - |
| メールアドレス | 常に表示 | 常に必須 | - |
| お問い合わせ内容 | 常に表示 | 常に必須 | - |
| 題名 | 表示/非表示 | 任意/必須 | 非表示 |
| 郵便番号 | 表示/非表示 | 任意/必須 | 非表示 |
| 住所 | 表示/非表示 | 任意/必須 | 非表示 |
| 電話番号 | 表示/非表示 | 任意/必須 | 表示（任意） |
| 性別 | 表示/非表示 | 任意/必須 | 非表示 |

**注意**: 名前、メールアドレス、お問い合わせ内容は常に表示・必須です。

---

### 2. フォーム表示設定

フォームの表示方法を設定します。

#### フォームタイプ

| タイプ | 説明 |
|-------|------|
| シングルページ | ショートコード `[inquiry]` で任意のページに埋め込み |
| 別ページ | 専用URLでフォームを表示（入力→確認→完了の3ステップ） |

#### シングルページモード

ショートコード `[inquiry]` をページコンテンツに挿入して使用します。

```
[inquiry]
```

#### 別ページモード

専用のURLでフォームを表示します。

- **URL設定**: `https://example.com/{スラッグ}`
- **デフォルトスラッグ**: `inquiry`
- **プレビューボタン**: 設定したURLを新しいタブで開いて確認

#### 確認画面の表示

| 設定 | 動作 |
|------|------|
| ON | 送信前に入力内容の確認画面を表示 |
| OFF | 確認画面なしで直接送信 |

---

### 3. 完了ページ設定

フォーム送信完了後に表示するページの内容を設定します。

| 項目 | 説明 | デフォルト値 |
|------|------|-------------|
| タイトル | 完了ページの見出し | 送信完了 |
| メッセージ | 完了ページの本文（HTML使用可） | お問い合わせありがとうございました。<br>内容を確認の上、担当者よりご連絡させていただきます。 |

---

### 4. 管理者通知設定

お問い合わせ受信時に管理者に送信されるメールの設定です。

| 項目 | 説明 | 必須 |
|------|------|------|
| 管理者メールアドレス | 通知メールの送信先 | ✓ |
| 件名 | 通知メールの件名 | |
| 本文 | 通知メールの本文テンプレート | |

#### 本文で使用できるプレースホルダー

| プレースホルダー | 置換される内容 |
|-----------------|---------------|
| `{{name}}` | お名前 |
| `{{email}}` | メールアドレス |
| `{{subject}}` | 題名 |
| `{{phone}}` | 電話番号 |
| `{{postal_code}}` | 郵便番号 |
| `{{address}}` | 住所 |
| `{{message}}` | お問い合わせ内容 |

#### 本文テンプレート例

```
以下の内容でお問い合わせを受け付けました。

お名前: {{name}}
メールアドレス: {{email}}
題名: {{subject}}
郵便番号: {{postal_code}}
住所: {{address}}
電話番号: {{phone}}

お問い合わせ内容:
{{message}}
```

---

### 5. 自動返信設定

お問い合わせ送信者への自動返信メールの設定です。

| 項目 | 説明 |
|------|------|
| 自動返信を有効にする | ON/OFFで切り替え |
| 送信元メールアドレス | 自動返信メールのFromアドレス |
| 件名 | 自動返信メールの件名 |
| 本文 | 自動返信メールの本文テンプレート |

#### 本文で使用できるプレースホルダー

管理者通知と同じプレースホルダーが使用できます。

#### 本文テンプレート例

```
この度は、お問い合わせいただきありがとうございます。

以下の内容で承りました。
内容を確認の上、担当者よりご連絡させていただきます。

お名前: {{name}}
メールアドレス: {{email}}
題名: {{subject}}

お問い合わせ内容:
{{message}}

今後ともよろしくお願いいたします。
```

---

### 6. セキュリティ設定

スパム対策の設定です。

| 項目 | 説明 |
|------|------|
| CAPTCHA認証を使用 | ON/OFFで切り替え |

**前提条件**: CAPTCHAを使用するには、事前に「設定」→「セキュリティ」でCAPTCHAの設定と認証テストを完了している必要があります。

---

## 警告メッセージ

### メールサーバー設定の警告

設定画面上部に以下の警告が表示される場合があります：

> メールサーバーの設定が完了していません。

**対処方法**: 「設定」→「基本設定」でメールサーバーの設定と3段階のテスト（接続・送信・受信）を完了してください。

### CAPTCHA設定の警告

セキュリティ設定セクションに以下の警告が表示される場合があります：

> CAPTCHAの設定が完了していません。

**対処方法**: 「設定」→「セキュリティ」でCAPTCHAの設定と認証テストを完了してください。

---

## 設定の保存

1. 各項目を設定
2. 画面下部の「保存」ボタンをクリック
3. 確認ダイアログで「保存」をクリック
4. 設定が保存され、成功メッセージが表示される

---

## データベース設定

設定は `inquiry_settings` テーブルに保存されます。

| カラム | 型 | 説明 |
|--------|-----|------|
| admin_email | string | 管理者メールアドレス |
| subject | string | 管理者通知件名 |
| body | text | 管理者通知本文 |
| use_recaptcha | boolean | CAPTCHA使用フラグ |
| show_phone | boolean | 電話番号表示 |
| phone_required | boolean | 電話番号必須 |
| show_address | boolean | 住所表示 |
| address_required | boolean | 住所必須 |
| show_subject | boolean | 題名表示 |
| subject_required | boolean | 題名必須 |
| show_postal_code | boolean | 郵便番号表示 |
| postal_code_required | boolean | 郵便番号必須 |
| show_gender | boolean | 性別表示 |
| gender_required | boolean | 性別必須 |
| auto_reply_enabled | boolean | 自動返信有効 |
| auto_reply_from_email | string | 自動返信送信元 |
| auto_reply_subject | string | 自動返信件名 |
| auto_reply_body | text | 自動返信本文 |
| use_single_page | boolean | シングルページモード |
| show_confirmation_page | boolean | 確認画面表示 |
| inquiry_url_slug | string | 問い合わせページURL |
| name_order_western | boolean | 欧米式名前順 |
| completion_title | string | 完了ページタイトル |
| completion_message | text | 完了ページメッセージ |

---

## 設定の取得（プログラム）

```php
use Plugins\DixlaseInquiry\App\Models\InquirySetting;

// 全設定を取得
$settings = InquirySetting::getSettings();

// 個別の設定にアクセス
$adminEmail = $settings->admin_email;
$showPhone = $settings->show_phone;
$autoReplyEnabled = $settings->auto_reply_enabled;
```

## 推奨設定

### 一般的なお問い合わせフォーム

```
フォーム項目:
- 名前: 表示・必須（固定）
- メールアドレス: 表示・必須（固定）
- 題名: 表示・必須
- 電話番号: 表示・任意
- お問い合わせ内容: 表示・必須（固定）

表示設定:
- 確認画面: ON

自動返信:
- 有効: ON
```

### シンプルなお問い合わせフォーム

```
フォーム項目:
- 名前: 表示・必須（固定）
- メールアドレス: 表示・必須（固定）
- お問い合わせ内容: 表示・必須（固定）
- その他: すべて非表示

表示設定:
- 確認画面: OFF（素早い送信）

自動返信:
- 有効: OFF
```

### 詳細な情報を収集するフォーム

```
フォーム項目:
- すべて表示・必須

表示設定:
- 確認画面: ON（入力ミス防止）

自動返信:
- 有効: ON
```
